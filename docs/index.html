ClipCrafter

Ferramenta de código aberto para criar e agendar YouTube Shorts a partir das suas lives e VODs de gameplay.

  • Gera clipes verticais 1080x1920 com legendas, hooks e normalização de áudio
  • Agenda publicações diárias via GitHub Actions
  • Publica apenas no seu próprio canal com a sua autorização (OAuth do Google)

Código-fonte: github.com/fercamitv-web/clipcrafter
